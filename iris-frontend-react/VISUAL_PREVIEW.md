### Colors
```
Primary Dark:     #1a1a2e  ███████

```

### Typography
- Font Family: Segoe UI, Tahoma, Geneva, Verdana, sans-serif
- Title: 4rem, bold, letter-spacing: 3px
- Headers: 2rem, bold
- Body: 1rem, regular
- Small: 0.85rem

### Effects
- Glass-morphism: backdrop-blur(10px), bg: rgba(255,255,255,0.05)
- Shadows: 0 10px 20px rgba(255, 215, 0, 0.3)
- Border Radius: 0.5rem (8px)
- Transitions: all 0.3s ease
- Hover: translateY(-2px)

### Spacing
- Container padding: 2rem (32px)
- Card padding: 1rem (16px)
- Gap between elements: 1rem
- Max content width: 48rem (768px)

## 11. Responsive Behavior

### Mobile (< 768px)
- Single column layout
- Stacked buttons
- Full-width cards
- Collapsible navigation
- Touch-friendly targets (min 44px)

### Tablet (768px - 1024px)
- 2-column grid for stats
- Side-by-side form fields where appropriate
- Optimized card sizes

### Desktop (> 1024px)
- 3-4 column grid for stats
- Wider content areas (max 1200px)
- Hover effects fully enabled
- Multi-column forms

---

## 12. Animations & Interactions

### Button Interactions
```
Default → Hover → Click

[Button]  →  [Button]  →  [Button]
              ↑ 2px          ↓
            + shadow      (Active)
```

### Modal Entrance
```
1. Overlay fades in (0.3s)
2. Modal scales from 90% to 100% (0.3s)
3. Content becomes interactive
```

### Toast Notifications
```
1. Slide in from right (0.3s)
2. Display for 4 seconds
3. Fade out to right (0.5s)
4. Remove from DOM
```

### Loading States
- Buttons: "Processing..." text + opacity 50%
- Lists: "Loading..." centered text
- Disabled inputs: opacity 50%, cursor: not-allowed
