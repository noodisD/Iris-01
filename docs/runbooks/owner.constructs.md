# owner.constructs

**What it means:** Constructs noticed by reading wait to be confirmed or rejected; until then nothing measures them.

**Confirm:** `SELECT count(*) FROM themes WHERE status = 'candidate'`.

**Safe fix:** Tell the owner; they review on the Constructs screen.

**Never:** Never confirm constructs for the owner.

See [README](README.md) for action classes and the rules every check follows.
