### /etc/hosts 

its like a local domain name service that you can use in your local device to simplify the process 

it simply assings the domain name to the IP adress and whenever you are using this name resolution on your machine 

Machine first checks the /etc/hosts if it contains mapping for that name. if so then it simply replacing your host-name with the IP adress you have provided to simplify your process without needing from you to remember the IP eaach time you want to use it 

The machine will always prioritize the /etc/hosts over the real DNS therefore at scale it can have a negative cosequences and for example if the IP of the host would change that it could brake the process that you have developed for it 

Assigned host-names never exist outside of your machine
