# resources.disk

**What it means:** The disk IRIS runs from is filling up.

**Confirm:** `df -h ~/Iris-01`; `du -sh data/*`.

**Safe fix:** Ask the owner what may go: old full backups, caches, recordings already imported.

**Never:** Never delete data/ contents without the owner.

See [README](README.md) for action classes and the rules every check follows.
