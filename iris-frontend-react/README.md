# IRIS React Frontend (DEPRECATED)

> **⚠️ WARNING**: This React-based frontend is now deprecated in favor of the high-performance **Vanilla JS** implementation located in the root directory (`iris_frontend.html`).

## Why the change?
To minimize dependencies, eliminate layout shifts, and achieve sub-500ms responsiveness, the project has transitioned to a single-file Vanilla JS architecture.
